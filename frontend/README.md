# Фронтенд Mountain & Sea Spa

React + TypeScript + Vite приложение для управляющего спа-объектом. Помогает контролировать остатки, видеть риски и принимать решения о закупках на основе расчётов mock API.

## Возможности

- Дашборд с KPI, предупреждениями и ближайшими заказами.
- Остатки с фильтрами, карточкой товара, партиями и движением с пагинацией.
- Предупреждения с уровнем риска, показателями и рекомендацией.
- Расчёт закупки с изменяемыми параметрами, предупреждениями и обоснованием: исходные данные, формулы и допущения.
- Список заказов на выбранный горизонт, план закупок и бюджет с разбивками и сравнением с предыдущим периодом.
- Динамика закупочных цен, себестоимость и маржинальность услуг, сценарий изменения цен.
- Чат с историей, примерами вопросов, таблицами, расчётами и кликабельными уточнениями.
- Выгрузка расчёта закупки, списка заказов и плана в JSON вместе с данными API.

## Стек

- React 19, TypeScript 6, Vite 8;
- React Router 7, TanStack Query 5, Axios и Zustand 5;
- CSS Modules, Vitest, ESLint и Prettier.

## Запуск

Frontend запускается как самостоятельный проект. Для работы с данными отдельно запустите backend API. По умолчанию frontend ожидает его на `http://localhost:8000`.

### Через Docker Compose

Из директории `spa-front/frontend` выполните команду в среде с доступным Docker (на Windows — через WSL):

```bash
docker compose up
```

Откройте <http://localhost:5173>. Compose собирает и запускает только frontend. Backend должен быть запущен отдельно и доступен браузеру по `http://localhost:8000`. Если он работает на другом адресе, задайте `VITE_API_URL` при запуске Compose. Внешний порт frontend можно изменить через `FRONTEND_PORT`. После изменения исходников пересоберите образ командой `docker compose up --build`.

### Локально

Нужны Node.js 24 и npm. Из директории `spa-front/frontend`:

```bash
npm ci
npm run dev
```

Dev-сервер передаёт запросы `/api` отдельно запущенному backend.

## Настройка API

Адрес API не задан в компонентах. При запуске через Docker Compose `VITE_API_URL` по умолчанию равен `http://localhost:8000`: браузер отправляет запросы напрямую в backend. Для локального запуска с пустым `VITE_API_URL` запросы на `/api` идут через прокси dev-сервера Vite; его цель задаётся переменной `VITE_API_PROXY_TARGET` (по умолчанию `http://localhost:8000`). Если backend доступен по другому адресу, укажите `VITE_API_PROXY_TARGET` в `spa-front/frontend/.env.local`. Для статической сборки укажите `VITE_API_URL` до `npm run build`. Пример значений — в [`.env.example`](.env.example).

Переключатель объекта загружает варианты из `/api/meta` и передаёт выбранный объект в поддерживающие его запросы. Эндпоинты цен и экономики услуг не имеют фильтра по объекту, поэтому их показатели относятся ко всей сети SPA.

## Архитектура

- `src/app` — глобальные провайдеры TanStack Query и React Router, регистрация страниц;
- `src/pages/<раздел>/ui` — экраны и их CSS Modules;
- `src/widgets/app-shell` — общий макет с навигацией;
- `src/features/location` — Zustand store выбранного объекта и селектор с учётом данных API;
- `src/entities/<домен>/api` — функции запросов и фабрики `queryOptions` для метаданных, склада, закупок, экономики и помощника; импорт через `index.ts` домена;
- `src/shared/api/client.ts` — единый Axios-клиент с обработкой ошибок; `endpoints.ts` — типизированный объект адресов API и кодирование параметров;
- `src/shared/config/routes.ts` — имена путей и пункты навигации, `src/app/router/router.tsx` — привязка путей к страницам;
- `src/shared/types.ts` — контракт ответов mock API; `src/shared/ui` — общие компоненты; `src/shared/lib` — форматирование и выгрузка JSON;
- `src/global.css` — базовая типографика и сброс стилей.

Зависимости направлены от верхних слоёв FSD к нижним: `app → pages → widgets → features → entities → shared`. Для нового экрана добавьте путь в `routePaths`, пункт меню в `navigation` (если нужен) и элемент маршрута в `app/router/router.tsx`. Для нового запроса добавьте адрес в `endpoints`, функцию и `queryOptions` в соответствующий домен. TanStack Query хранит серверные данные и разделяет кеш по параметрам запроса, Zustand хранит только выбранный объект. Показатели закупок и бюджета frontend не рассчитывает: он отображает значения из API. Для запросов предусмотрены состояния загрузки, ошибки и пустого результата. Тесты композиции API находятся в `src/app/api-composition.test.ts`.

ESLint проверяет TypeScript и правила React Hooks. Prettier задаёт формат через `.prettierrc.json`; перед коммитом выполняйте `npm run lint`, `npm run format:check`, `npm test` и `npm run build`.

## Данные демонстрации

Mock API использует синтетические данные и хранит историю чата в памяти. После перезапуска backend история очищается, а набор данных строится заново на текущую дату. Интерфейс показывает рекомендации, но не размещает заказы автоматически.
